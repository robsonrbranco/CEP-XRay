Autenticação

Dois passos: o Basic troca por um token, o token vale uma hora.

# 1. token
curl -X POST https://hestia.ecomciencia.com/token/v1/autentica \
     -u "$USUARIO:$CODIGO_ACESSO"

# {"token":"eyJhbGciOiJIUzI1NiJ9...","expiraEm":"...","apis":["cep"]}

# 2. consulta
curl https://hestia.ecomciencia.com/cep/v2/enderecos/01001000 \
     -H "Authorization: Bearer $TOKEN"

Para agentes de IA: MCP

Além do contrato dos Correios, o Hestia fala o Model Context Protocol em POST /mcp — o padrão aberto pelo qual plataformas agênticas descobrem e usam ferramentas. O agente consulta CEP como uma ferramenta, sem código de integração, e deixa de preencher endereço de memória.

Plugar e usarRegistre a URL e o token no cliente MCP do agente. As ferramentas aparecem sozinhas, com descrição e parâmetros.
Segredo fora do modeloO token fica na configuração do cliente. O modelo vê as ferramentas, nunca a credencial.
Resposta enxutaSem os campos que o contrato dos Correios manda sempre nulos, e com a competência do dado em toda resposta.
Salvaguardas no protocoloO servidor avisa ao modelo que a base é um retrato, que texto de cadastro é dado e não instrução, e que base fora do ar é valor desconhecido — não endereço inventado.
FerramentaO que faz
consultar_cepEndereço de um CEP. Devolve encontrado: false se o CEP não estiver na competência servida
buscar_enderecosBusca por UF, município, bairro ou prefixo do logradouro, até 50 por página
listar_localidadesMunicípios, com o id usado na busca, o código IBGE e o DDD
hestia://competenciaRecurso: de qual extrato vêm as respostas
 
# OpenClaw
openclaw mcp add hestia --url https://hestia.ecomciencia.com/mcp \
     --header "Authorization=Bearer $TOKEN_MCP"

# Claude Code
claude mcp add --transport http hestia https://hestia.ecomciencia.com/mcp \

O token do MCP é outro

Não é o token de uma hora do /token/v1/autentica: é emitido pela Ecomciência para a sua credencial, vale até um ano e só funciona em /mcp — as rotas REST o recusam, e o /mcp recusa o token delas. Revogar a credencial ou trocar o código de acesso o invalida na hora. Para obter, escreva para contato@ecomciencia.com.

Mesma cota, mesma cobrança

Cada consulta pelo MCP conta como uma consulta da API; descobrir as ferramentas não conta. O CEP consultado não é registrado, pela mesma razão que no REST: um CEP diz onde alguém mora.

Autenticação por cabeçalho

Funciona com qualquer cliente MCP que envie cabeçalho de autorização — conferido com o cliente oficial do protocolo e com o OpenClaw. Conectores que exigem login OAuth ainda não são atendidos.

Três diferenças em relação aos Correios

Nenhuma delas é do código: são da fonte, e por isso nenhuma implementação as fecha. Estão aqui porque descobri-las meses depois, num chamado de suporte, é pior.

A base é um retrato de uma competência

Não é o DNE ao vivo. Um CEP criado depois do fechamento da competência não está aqui, e uma rua que mudou de nome ainda aparece com o nome antigo. O /saude e o /cep/v1/atualizacao dizem qual competência está no ar.

Seis campos saem sempre nulos

abreviatura, numeroLocalidade, cepUnidadeOperacional, numeroInicial e numeroFinal não existem no extrato — e nomeUnidade só é preenchido em CEP de grande usuário. Eles vêm na resposta como null, nunca ausentes, para não quebrar cliente gerado do OpenAPI. numeroLocalidade em especial nunca recebe o código do IBGE: é outra numeração, e entregá-la ali seria um erro que o cliente não teria como perceber.

Três recursos devolvem 501

Cliques, caixas postais e agências modulares respondem sobre cobertura de serviço por localidade, e o extrato não traz atributo de serviço. Devolver uma lista derivada de busca textual daria uma resposta com aparência de autoridade e conteúdo de palpite.
